# Contributing

Axolotl-PM will always be free and open-source, but it requires a lot of time and effort from unpaid volunteers to develop.

There are a few ways to contribute to the effort.

## Reporting bugs

Our team makes the best effort to stop bugs from making it to releases, but sometimes things will slip through the net.

If you run into a bug, please make sure to report it so that our team can fix it.

Check out the [Issues](/docs/issues/github-issues) section to find out how to make a bug report.

::: info Note
Please don't assume that bugs will magically be fixed.

If you don't report them, we may not find out about them and they won't get fixed.
:::

## Translations

We provide translations for Axolotl-PM in many different languages, but since the core team doesn't know many of them, we rely on outside contributors to add and proofread translations.

Head over to the [Axolotl-PM Weblate project](https://translate.axolotl-pm.org) to get started.

::: tip Tip
Submitted translations require approval from a proofreader to be released in Axolotl-PM.

Some languages may already have been fully translated, but lack proofreaders.

If you're fluent in English and another language, and you're interested in becoming a proofreader,
join our [Discord](https://discord.gg/vrPugybpJF) and ask us being proofreader.
:::

## Code contributions

Want to have a more direct role in improving Axolotl-PM?

You can propose improvements using the GitHub pull request system.

Check out the [Axolotl-PM internals docs](/docs/developers/internals-docs-index) section to get started.

::: tip Tip
Look on the bug tracker for [issues labelled "Easy task"](https://github.com/axolotl-pm/PocketMine-MP/issues?q=is%3Aissue%20state%3Aopen%20label%3A%22Easy%20task%22) to get started with.
This will help you familiarise yourself with the codebase.
:::

::: info Note
Submit a [Feature Proposal](https://github.com/axolotl-pm/PocketMine-MP/issues/new?template=feature-proposal.yml) issue on GitHub to get the team's feedback before starting work on any large changes.

As we may decline PRs that don't suit Axolotl-PM's goals, to avoid wasting your time or ours, it's best if any big changes are discussed with the team before starting work on them.
:::

## Donating

Axolotl-PM is free, but it requires a lot of time and effort from unpaid volunteers to develop. Donations enable us to keep delivering support for new versions and adding features your players love.

Check out the [GitHub README Donating](https://github.com/axolotl-pm/PocketMine-MP/tree/stable?tab=readme-ov-file#donate) section for up to date donation methods.
